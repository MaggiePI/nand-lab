Meet N8
Four 8-bit registers. A 4-bit opcode. Two bytes per instruction. Unified 256-byte memory.
Clock advances one phase. Instruction completes the current instruction. Run advances continuously; pause to inspect any state.
ADD / SUB / CMP update Z (zero), C (carry or no borrow), V (signed overflow). Logical operations clear C and V. SHL shifts left and copies the old top bit into C. Loads and branches preserve flags.
The ALU and register input multiplexers use NAND-derived Boolean gates. Memory and sequential state are host objects. The diagram shows architectural data flow, not electrical timing.
Program bytes occupy 00–BF. C0–CF drive the pixel screen. ST to F0 prints a byte; LD from F1 consumes queued input or returns zero.
